# AI-use transparency

AI assistance is welcome when it is disclosed and reviewed. For project-relevant
code, tests, documentation, configuration, security analysis, or generated
assets, a pull request must state:

- the tool, system, or category when known;
- the artifacts or sections it assisted;
- why it was used; and
- the human review, tests, or other validation performed.

If none was used, write `No AI assistance`.

Disclosure is informational, not punitive, and does not require details about
private personal use unrelated to the contribution. AI assistance never replaces
contributor responsibility, review, testing, security checks, or license and
attribution obligations.

Never submit private prompts, secrets, household data, recordings, personal
data, regulated data, or unpublished security details to an external AI service.
Use local tools or sanitized public-safe material when those boundaries matter.
