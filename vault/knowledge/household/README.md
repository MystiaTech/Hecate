# Household notes and procedures

Use this area for non-secret household facts, maintenance notes, and procedures.
Record the source and last-verified date when accuracy matters. Procedures are
reference material only and do not authorize Hecate to perform actions.

Suggested note fields:

- purpose;
- source or owner;
- last verified;
- procedure or reference details; and
- cautions and confirmation requirements.
