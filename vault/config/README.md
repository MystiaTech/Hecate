# Executable configuration boundary

This directory is reserved for future machine-readable configuration and its
documentation. It is intentionally separate from [`../knowledge/`](../knowledge/)
so Markdown notes cannot be interpreted as executable configuration.

No runtime configuration format or behavior has been implemented yet. Future
configuration must be validated before use and must not contain credentials,
lock codes, camera tokens, API keys, or other secrets committed to Git.
